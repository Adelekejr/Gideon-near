01 / HOW IT WORKS

One call before every transfer.

01
Agent prepares a send

From a user request, an invoice or another agent: token, amount, recipient.

02
It asks Gideon

Format and network, cross-chain hash lookups, account state, token contract, Intents deposit status, exchange rules and lookalikes.

03
Sends, or asks

On BLOCKED the agent stops and asks for exactly what’s missing. If a source is down the answer is “couldn’t check”, never “safe”.
