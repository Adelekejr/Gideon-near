Browser extension · v0.2.1 · Chrome, Brave, Edge, Firefox

It checks the moment you paste.

On NEAR wallet and exchange pages, Gideon watches the recipient field. Paste a wrong, poisoned or lookalike address and a warning card appears right under it, the Send button is held, and the Arrow G shows you why. Same rules as the checker, read-only, no keys.

01 / On the page

What it does on a page.

  1. Checks on paste

    Recipient fields on NEAR wallets and exchanges: named .near/.testnet accounts, 64-character implicit accounts and 0x addresses.

  2. Holds the Send button

    While a check says BLOCKED the page’s Send or Withdraw button stays held. ATTENTION warns but lets you decide.

  3. Watches the clipboard

    If a page swaps what you copied for a lookalike, Gideon says so at the moment you paste (rule R9).

02 / Install

Install it.

Chrome · Brave · EdgeMV3
npm run zip:extension # chrome://extensions → Developer mode → Load unpacked # → apps/extension/dist (or gideon-extension-0.2.1.zip)
FirefoxMV3
npm run zip:extension # about:debugging → This Firefox → Load Temporary Add-on # → gideon-extension-firefox-0.2.1.zip

Permissions: storage only. It reads the page you are on locally and asks public NEAR RPC for account state. It never touches keys and can’t move funds.
